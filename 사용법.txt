웻지 포지션 배치 프로그램 사용법

==================================================
1. 그냥 PC에서 바로 쓰기 (인터넷 필요 없음)
==================================================
index.html 을 더블클릭하면 크롬/엣지에서 열립니다.
폴더를 통째로 복사해서 쓰면 되고, 이 방식에서는 앱 설치 기능만 빠집니다.

==================================================
2. 앱으로 쓰기 - 처음 한 번만 인터넷에 올리기 (GitHub Pages, 무료)
==================================================
[올리기 - 담당자 한 명이 한 번만]
1) https://github.com 에서 계정을 만듭니다.
2) 오른쪽 위 + > New repository
   - Repository name: wedge-position (영문으로)
   - Public 선택 > Create repository
3) 생성된 화면에서 "uploading an existing file" 클릭
4) 이 폴더 안의 파일과 icons 폴더를 전부 끌어다 놓습니다.
   (폴더 자체가 아니라 index.html, app.js ... icons 가 맨 위에 오도록)
   > 아래 Commit changes 클릭
5) 저장소 위쪽 Settings > 왼쪽 Pages
   - Source: Deploy from a branch
   - Branch: main / (root) > Save
6) 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다.
   예) https://아이디.github.io/wedge-position/
   이 주소를 연구실 사람들에게 공유하면 됩니다.

[앱 설치 - 각자]
- 안드로이드: 크롬으로 주소 열기 > 오른쪽 위 ⋮ > "홈 화면에 추가" 또는 "앱 설치"
- 아이폰/아이패드: 사파리로 주소 열기 > 공유 버튼 > "홈 화면에 추가"
- 윈도우 PC: 크롬/엣지로 주소 열기 > 주소창 오른쪽 설치 아이콘(모니터 모양) 클릭
  > 바탕화면/시작 메뉴에 아이콘이 생기고 독립된 프로그램 창으로 실행됩니다.
한 번 열어 둔 뒤에는 인터넷이 끊겨도 실행됩니다.

[수정해서 다시 올릴 때]
1) 파일을 고칩니다 (보통 config.js).
2) service-worker.js 를 메모장으로 열어 VERSION = 'v1' 을 'v2' 처럼 하나 올립니다.
3) GitHub 저장소 화면 > Add file > Upload files 로 바뀐 파일만 다시 올리고 Commit.
4) 각자 앱을 한 번 껐다 켜면(필요하면 두 번) 새 버전으로 바뀝니다.

==================================================
파일 구성
==================================================
index.html          : 실행 파일 (화면 구성)
config.js           : 설정 파일 - 대부분의 수정은 여기서만 합니다
app.js              : 계산 규칙과 화면 그리기 코드
style.css           : 색상, 글꼴 등 모양
manifest.json       : 앱 이름, 아이콘 정보
service-worker.js   : 오프라인 실행용 (수정 시 VERSION만 올리면 됨)
icons/              : 앱 아이콘

==================================================
자주 바꿀 만한 설정 - config.js
==================================================
메모장으로 config.js를 열어 숫자만 바꾸고 저장한 뒤 새로고침(F5).
- 자 중앙 눈금(rulerCenter): 웨이퍼 중앙에 맞추는 자 눈금. 기본 15
- 샘플 크기 목록(sampleSizes): 예) [1.0, 1.2, 1.5]
- 여유 마진 기본값(defaultMargin): 기본 0.5
- 처음 열 때 들어 있는 공정 번호/포지션
- 쿠폰이 겹칠 때 처리 방식(mergeMode): "long" 긴 쿠폰 / "shrink" 마진 축소
쉼표(,)와 따옴표(" ")는 지우지 않도록 주의하세요. 잘못 고쳐서 화면이 비어 보이면
원본 config.js로 되돌리면 됩니다.

참고: 마지막으로 입력한 값은 각자 기기에 자동 저장되어 다음에 그대로 나옵니다.
config.js의 기본값은 저장된 입력값이 없을 때(처음 열 때) 적용됩니다.
